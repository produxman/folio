# Project Images

This directory contains preview images for the "Things I'm Building" carousel.

## Required Images

- `bazyl-preview.png` - Screenshot of Bazyl app
- `chatbot-preview.png` - Screenshot of portfolio chatbot
- `framework-preview.png` - Visual of product strategy framework
- `metrics-preview.png` - Screenshot of SaaS metrics dashboard
- `api-hub-preview.png` - Visual of API integration hub

## Image Specifications

- **Dimensions**: 800x600px (4:3 aspect ratio) recommended
- **Format**: PNG or WebP
- **Size**: Keep under 200KB for optimal loading

## Fallback

If images are not found, the carousel will display a gradient background with the project status badge.
